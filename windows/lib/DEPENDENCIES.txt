Total managed deployment: 3,281,296 bytes (about 3.13 MiB).
The helper requires Windows 8 or newer, .NET Framework, and user-approved elevated
execution for ETW kernel events. No driver, packet capture or global package install
is performed. Windows named real-time sessions use built-in ETW; the native symbol
and KernelTraceControl binaries from the package are not deployed or used.
The helper never starts the legacy global NT Kernel Logger session.

Collection: TCP and UDP IPv4/IPv6 Send/Recv PID and size counters, plus process
name/lifetime metadata to separate reused PIDs. No network content, endpoints,
command line, stack, ETL trace file or process credentials are written.
Stats are observed ETW event bytes, not physical NIC bytes. VPN/proxy/app layers
may count the same logical transfer more than once. Reported lost events mark
incomplete observations. Live snapshots replace one JSON file; no history is
written by this helper. Ordinary stop, parent exit and handled failures dispose
only the helper's named session. Forced termination/power loss cannot run cleanup.
