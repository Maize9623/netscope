# NetScope 第一版验证记录

日期：2026-10-29，Windows 本机验证。

## 已通过

- 最终源码与私有依赖编译成功，生成 x64 Windows 程序。
- **158 项离线检查通过，7 组测试均退出码 0**。覆盖诊断边界、HTTP 401/403/404/405/407/429/5xx、漏测与内部错误、配置切换、延迟基线、隐私摘要、CSV安全、坏尾行恢复、设备标签、额度解析、AI结构化报告、进程异常规则、进程计数与非管理员权限分支。明细见 tests/验证结果.txt 和 tests/results。
- 独立回环测试验证 9 种 HTTP 状态、只发 HEAD、不跟随重定向、最大 4 并发、约 1 秒超时截止、内部忙标记及计数预热。可通过 tests-loopback.ps1 单独复跑；默认主测试不启动网络监听。
- 本机真实网络采集：物理 Wi-Fi 与疑似 VPN 虚拟网卡分开识别；本机邻居缓存及 IPv4/IPv6 TCP 连接表能够读取。未扫描局域网，也未做他人设备反向身份推断。
- 修复检测器线程池阻塞和本机 TLS 兼容问题后，一轮 7 个默认目标全部收到 HTTP 响应。后续独立采样也观察到个别接口单次超时；未把实际网络波动强制改成全绿。
- 已登录 Codex 实际分析成功：纯文本测试返回 15,932 输入 / 456 输出 token；结构化测试返回 16,181 输入 / 588 输出 token。后者产生 4 项证据、4 种备选解释和低把握结论，符合真实单次样本的限制。
- 额度只读接口真实返回共享窗口、套餐、积分原值、可用重置次数与到期时间；未执行重置或购买。
- 真实数据的八个页面、AI三个分层标签和小窗口均进行 WinForms 自有控件渲染检查。合成布局夹具只用于验证排版，交付预览来自真实测试结果。
- 数据与代码随包；第三方依赖许可证及哈希位于 lib。

## 已知未验证范围

- **管理员权限下的真实 ETW 事件字节路径尚未现场验证。** 未替用户点击 UAC、未自动启动管理员采集；需在程序中主动启用后进一步对照物理网卡、已知下载量与进程结果。19 项该模块测试验证的是计数逻辑、身份边界、丢事件及非管理员分支，不等于已做管理员现场测试。
- 尚未完成整天持续挂机的现场耐久验证，也未在公司的网络/网关上验证。
- 全公司设备的实时流量需要网关/AP遥测；当前是本机数据、邻居缓存和用户导入的网关快照。
- 未实现 macOS、Bonjour/mDNS自动发现、所有AI厂商的付费推理/流式会话检测或自动修改DNS/VPN。
- 单机、单路径和有限采样无法保证唯一根因；AI分析是辅助解释，不是对IT或供应商的责任证明。

## 如何复现

在本目录运行 build.ps1 重建，再运行 tests.ps1。默认测试不调用模型、不查询外部网站、不请求UAC、不启动ETW监听；可选 -LiveQuota 只读取已登录账号额度。tests-loopback.ps1 仅绑定本机回环地址，需要显式运行。
