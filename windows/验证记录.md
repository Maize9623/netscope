# NetScope v0.3 验证记录

本轮把主界面改为网络状态、主要检查按钮和六项可展开结果；新增设备首次自动读取、物理连接与 VPN 分区，以及用户手动触发的有限设备查找。普通后台不会运行设备扫描。

- Windows 正式源码已本地编译成功；13 组离线回归共 **321 项通过**。覆盖测量分类、未知值、历史隔离、AI JSON/隐私、额度、进程字节、网卡识别、设备身份、有限发现、取消与 UI 行为。
- 设备查找使用伪造路由、传输和缓存测试，没有对用户局域网执行网段扫描；实际效果还要由用户手动点击后验证。
- 正常窗口首次启动的回归确认：不预填设备、不切页面、不手动刷新，也能读到系统设备记录；没有启动 AI、HTTP 检查或主动发现。
- 日间、夜间、1000/1400 宽窗口、六问展开收起、设备分区与全部页面经过真实 WinForms 控件渲染检查，中文标题下缘和品牌名完整。
- 已登录 Codex 的大白话报告在 2026-10-29 23:07、23:16 等时间实际验证过；本轮 UI 与设备回归不额外调用模型。
- 管理员 ETW 尚未在当前用户机器上启动真实管理员捕获；设备分类的独立 AI 请求尚未用真实设备资料验证。
- 尚未完成全天挂机、全部 VPN 和睡眠唤醒验证，不承诺固定每日流量或绝对无开销。

编译保留 CS4014 提示，涉及有意不阻塞主流程的超时清理 continuation；这些任务会观察异常、维持底层并发上限。构建无错误。

跨平台自动构建结果见 GitHub 仓库 Actions 与 docs/validation.md。测试源码随软件保存；真实监测记录、标签和登录资料不进入 GitHub。
