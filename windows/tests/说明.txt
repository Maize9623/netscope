NetScope 验收测试

在 Windows PowerShell / PowerShell 中执行：
  .\tests.ps1

脚本将最新 source 编译为独立测试程序集，保存在系统临时目录，不替换正在运行的 NetScope.exe，不修改应用的真实数据。默认运行十三组本地合成测试，当前普通权限环境合计 321 项。不会开启监测定时器、调用 AI 模型、访问网络、扫描局域网、请求 UAC 或启动 ETW。

可选参数：
  .\tests.ps1 -OutputDirectory 'C:\your\test-output'
  .\tests.ps1 -LiveQuota

-LiveQuota 额外通过本机已登录的 Codex 只读查询真实额度，不调用模型，不消耗免费重置机会。只保存已选择的配额字段，不保存账号标识、认证内容或邮箱。

脚本自动引用 lib 中的托管 DLL 并复制运行依赖。每次执行生成 summary.txt 及十三组测试结果；失败会以非零退出码报告。

测试组及检查数：DiagnosticsTests 39、ControllerReviewTests 8、QuotaClientTests 9、FinalIntegrationTests 16、AiReportTests 34、ProcessInsightsTests 33、ProcessTrafficTests 19、DeviceAITests 25、DeviceIdentityTests 30、CollectorAdapterTests 34、DeviceDiscoveryTests 49、DiscoveryControllerTests 15、UiRegression 10。

ProcessTrafficTests 覆盖内部字节计数、实际窗口速率、百分比分母、累计值、PID 复用实例隔离、丢事件、有界缓存、PermissionRequired 和原子 JSON 覆盖。若用户从已提升终端运行，仅跳过 3 项非管理员守卫检查，仍不启动 ETW。

DeviceIdentityTests 使用注入解析器，不发送真实 DNS；覆盖 32 个已知邻居上限、2 个底层任务上限、超时后槽位保持、有界缓存、人工标签及来源保护。生产名称查询只由用户点击触发，名称并非主人身份。

DeviceDiscoveryTests 使用伪路由、伪 ICMP 与伪缓存，绝不探测真实网段。覆盖 RFC1918 与实际子网和 /24 的交集、8 并发、总时限、取消、VPN 路由跳过、只统计真正发送、未回应不等于无人、失败邻居条目过滤、DHCP 换 MAC 不继承身份、底层缓存任务共享。DiscoveryControllerTests 覆盖合并与取消注册竞态、10 分钟回应证据、历史保留期；UiRegression 使用虚构地址和 MAC 验证 10 项界面行为，不启动在线流程。

可选回环套件（不包含在默认 tests.ps1 中）：
  .\tests-loopback.ps1
  .\tests-loopback.ps1 -OutputDirectory 'C:\your\loopback-output'
它仅在 127.0.0.1 的系统分配端口启动临时 HTTP 服务，不访问外部 HTTP 或 DNS；验证 200/401/403/404/405/407/429/503/302 分类、仅 HEAD、禁重定向、四并发、超时、内部忙碌 Skipped、预热/过期基线与本机自报名称。407 单独标为代理认证，尚未验证目标服务。约 15 秒，要求存在已启用且有网关的物理接口以验证预热；只读本机网卡及邻居缓存，不扫描网段。不计入默认 321 项。
