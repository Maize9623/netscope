NetScope 验收测试

在 Windows PowerShell / PowerShell 中执行：
  .\tests.ps1

脚本会把最新 source 编译为独立测试程序集，保存在系统临时目录，不替换正在运行的 NetScope.exe，不修改应用的真实数据。
默认运行九组纯本地测试：诊断口径、控制器隐私与统计、额度解析、设备标签/设置/CSV/历史恢复集成验收，以及结构化 AI 报告解析、进程流量趋势规则、ETW 内部计数与非管理员权限守卫。不会开启监测定时器，不调用 AI 模型，也不访问外部网络。

可选参数：
  .\tests.ps1 -OutputDirectory 'C:\your\test-output'
  .\tests.ps1 -LiveQuota

-LiveQuota 额外通过本机已登录的 Codex 只读查询真实额度，不调用模型，不消耗免费重置机会。只保存已选择的配额字段，不保存账号标识、认证内容或邮箱。

脚本自动引用 lib 中的托管 DLL，并复制运行依赖，因此新增 ETW 依赖后仍可使用。测试不会启动 ETW 监听或要求管理员权限。
每次执行在输出目录生成 summary.txt 及九组测试结果；测试失败会以非零退出码报告。



ProcessTrafficTests 共 19 项（当前非管理员环境）：内部字节计数、实际窗口速率、百分比分母、累计值、PID 复用实例隔离、丢事件、有界缓存，以及 PermissionRequired 与原子 JSON 覆盖。不会请求 UAC 或创建 ETW 会话。若用户从已提升终端运行，仅跳过 3 项非管理员守卫检查，仍不启动 ETW。

可选回环套件（不包含在默认 tests.ps1 中）：
  .\tests-loopback.ps1
  .\tests-loopback.ps1 -OutputDirectory 'C:\your\loopback-output'
它只在 127.0.0.1 的系统分配端口启动临时 HTTP 服务，不访问外部 HTTP 或 DNS；验证 200/401/403/404/405/407/429/503/302 分类（407 单独标为代理认证，未验证目标服务）、仅 HEAD、禁重定向、最多四并发、超时、内部忙碌 Skipped、预热/过期基线和本机自报名称。测试约 15 秒，并要求存在已启用且有网关的物理接口，以验证自动接口速率预热。它读取本机网卡和邻居缓存，不扫描网段。此套件不计入默认 213 项。



DeviceAITests 共25项、DeviceIdentityTests共30项，完全使用本地合成数据/注入解析器。名称识别仅由用户点击触发，生产路径使用系统DNS；测试本身不发送PTR或其他DNS请求，不调用模型。测试覆盖已知邻居32项上限、2个真正未完成的任务上限、2秒等待预算、超时后的槽位保持、缓存和人工标签来源保护。未在真实局域网验证设备是否配置了可用的名称记录，未把解析结果当作主人的身份。
