# 验证记录

## Windows

第一版在当前 Windows 电脑构建、启动并进行真实网络及 Codex 集成验证。7 组离线测试共 158 项通过；包括状态分类、漏测处理、时间/路径隔离、AI 报告校验、额度缺失值与进程字节统计逻辑。另测本机 HTTP 服务的 9 类返回结果、并发限制及超时。

收到使用者反馈后，正在修订小白模式、文字裁切、日夜主题和报告措辞；修订版本需重新构建和验证。

Windows 管理员 ETW 的逻辑测试已通过，真实管理员会话尚未在用户机器上开启；全天挂机测试尚未完成。

## macOS

在 Windows 上开发 Swift 源码，计划由 GitHub Actions 的 macOS runner 编译、测试并产生 Apple Silicon 应用。本地 Windows 环境不能验证 Mac 的实际窗口、系统权限、睡眠唤醒和真实网络表现。

M4/M5 真机体验与公司网络长期记录仍待实际使用。各次构建的日志以仓库 Actions 为准，不将未运行的测试记为通过。
